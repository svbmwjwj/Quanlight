# 检测自动，发布手动

## 决定

- 自动部分只做检测：定期汇总各一级来源的变化并试构建，生成待审报告，不发布。
- 发布在本人空闲时进行：先做真机检测或探针，检测通过后再发布，不设固定周期。
- 配置中的规则集不设置自动更新时间，发布后在设备上手动更新。

## 备选

- 每日自动发布：上游变化未经真机验证就进入设备。
- 固定每两周检测一次：本人的空闲时间不固定。

## 缘由

用户认为既然真机检测不可或缺，发布就应在检测之后；检测时间由用户决定。
