# 仓库命名为 quanlight

## 决定

仓库、本地开发目录与本机数据目录统一命名为 `quanlight`。

## 备选

- semaquan：semaphore 与 Quan 组合。
- quansignal：Quan 与 signal 组合。
- trafiquan：traffic 与 Quan 组合。

## 缘由

用户要求用红绿灯与圈 X 组合成自造词，与 `~/Developer` 下其他项目的命名方式一致；从候选中选定 `quanlight`。
