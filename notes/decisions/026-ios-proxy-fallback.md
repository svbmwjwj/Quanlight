# iOS 改为代理托底，与 macOS 共用一套白名单

## 决定

iOS 与 macOS 都用代理托底：只为中国大陆常用的地址写直连规则，未命中的流量全部走代理。两类设备订阅同一组直连列表，配置模板分开。规则库的主体从境外服务包改为直连列表。

阶段随之调整：第 1 阶段骨架已完成；第 2 阶段改为共用白名单的直连列表与 APNs 包；第 3 阶段只剩 macOS 配置模板。

## 被推翻的原判断

D-007 让 iOS 用黑名单：只为确定在用的境外服务写代理规则，未命中全部直连。理由是手机上的国内应用多，白名单漏判会让它们走代理。D-010 据此把第 2 阶段定为 iOS 黑名单的服务包，第 3 阶段为 macOS 白名单。

## 备选

- 维持 iOS 黑名单：境外服务每缺一条就要补一条，Claude 等服务还要靠真机观测收窄依赖，维护成本高。

## 缘由

用户决定 iOS 也用代理托底，只整理直连规则。国内应用误走代理的风险，由宽口径的直连域名与大陆 IP 回退共同压低（D-028）。
